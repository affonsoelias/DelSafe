Module geometria

CreatePoint

function CreatePoint(x: Float64, y: Float64) return Point;

Creates a new point on the Cartesian plane.

```aether var p: Point := CreatePoint(10.0, 20.0); Assert(p.x > 0.0); ```

require: x >= 0.0
