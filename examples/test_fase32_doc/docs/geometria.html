Módulo geometria

Módulo de cálculos geométricos e estatísticos de alta precisão.

Fornece estruturas, contratos formais e funções com semântica estrita de posse.

Funções & Métodos

CriarPonto

function CriarPonto(x: Float64, y: Float64): Ponto;

Cria um novo ponto no plano cartesiano.

```aether var p: Ponto := CriarPonto(10.0, 20.0); Assert(p.x > 0.0); ```

require: x >= 0.0
require: y >= 0.0
ensure: x >= 0.0

Parâmetros

ParâmetroSemântica de PosseTipoDescrição
xFloat64Coordenada X
yFloat64Coordenada Y

Exemplo Testável (Doctest)

var p: Ponto := CriarPonto(10.0, 20.0);
Assert(p.x > 0.0);
