# Curso Oficial: Aprendendo Aether do Zero 🚀

Seja muito bem-vindo ao curso oficial da linguagem de programação **Aether**!

Este curso foi desenhado para ser direto, prático e sem rodeios. Em cada lição você aprenderá um conceito fundamental através de exemplos de código claros que você pode compilar e rodar imediatamente na sua máquina.

---

## 🎯 Para Quem é Este Curso?
- **Programadores Pascal / Delphi:** Que querem uma linguagem com sintaxe familiar, mas com o poder, a segurança de memória e a modernidade das ferramentas do século XXI.
- **Desenvolvedores C / Rust / Go / C++:** Que buscam uma linguagem com tempo de compilação ultra-rápido, zero coletor de lixo (*garbage collector*) e código limpo sem excesso de símbolos enigmáticos.
- **Iniciantes em Programação de Sistemas:** Que querem aprender a criar programas rápidos e nativos sem medo de travamentos por ponteiros nulos ou vazamentos de memória.
